## 实现

- 桌面内容上限 1440px，待办栏 320px，间隔 24px；768–1023px 待办栏 280px；窄窗口保留待办／时间线切换。
- 顶部集中导航与工具；日期、时间范围、5/15/30 分钟精度独立成行。保留周／日跳转、今日、直接专注、当前会话、批量改期、撤销和快捷键帮助。
- 移除重复的桌面新增任务入口、重复的负载区和应用副标题；保留对象名称、操作依据及状态。手机端压缩间距，将快捷键帮助收为 `?`，功能及可访问名称保留。
- 名称自然换行；开始专注常显；次要操作预留位置，在 hover/focus 时出现，触屏全部可见且至少 48px。按钮点击和键盘事件独立于外层卡片排期。
- 搜索保留显式提交、全部筛选、100 条展示上限及原有跳转摘要；统一输入、结果、空结果样式。
- 专注面板上限 520px，桌面倒计时 64px、轻量进度环，同一主按钮外壳承载开始／暂停／继续和处理状态。
- 命令处理期间禁用重复操作；保存确认前不提供休息操作，失败保留任务和重试入口；完成后显示绿色勾选及休息／返回计划，移除运行态鼓励语。
- 修复计时状态 effect 随父组件回调身份变化反复发布的警告；依赖实际任务与计时字段，回调通过最新 ref 调用。
- 撤销成功提示移至下方，避免遮挡顶部工具；关闭按钮具备明确名称。
- 修复空时间槽覆盖层拦截拖放事件的问题，将事件监听放在原时间槽容器；现有调度器的日期、冲突、时长及刻度判定不变。

## 动效

原生 CSS 实现，没有引入动画依赖或以动画触发业务提交。

| 动作 | 时间与反馈 |
| --- | --- |
| 主按钮按下 | 80ms 缩至 97% |
| 按钮图标替换／次要操作显现 | 150–160ms |
| 选中底板移动 | 210ms |
| 首次内容／专注面板／保存操作区展开 | 250–280ms |
| 进度环 | 1000ms 线性跟随剩余时间 |

减少动态效果时禁用动画和过渡；CSS 过渡可以从当前值中断。处理中的状态由运行时及保存结果驱动，操作无需等待动画结束。

动效交付为三组实际“开始／中间／结束”截图，分别记录底板切换、专注面板出场、暂停按钮按压及替换。中间帧同时记录 `document.getAnimations()` 的运行状态及变换矩阵，见 [验证记录](ui-motion/evidence/validation.json)。当前机器没有 Playwright 所需 FFmpeg，未生成连续录像；过程帧不能证明帧率或连续流畅度。
