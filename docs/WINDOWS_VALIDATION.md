补充审查确认损坏文件归档失败后的重试不能绕过归档要求；相应状态保留与组合回归已补齐。最终复审没有确认的未解决规范缺陷。最严重的原退出保存问题已解决；物理断电耐久性仍属于下方系统验收边界。

## 使用与回退

日常切换前先导出新版完整 v8 备份，并保留 0.1.3 程序及对应 v6 兼容备份。v6/v7 不携带精确会话、新排期精度和独立历史估算等新增字段；导出界面有明确说明。v8 不应直接交给只识别旧格式的程序。

运行中、暂停、待提交及待恢复会话必须结束或明确放弃后再导入或恢复；应用先保存操作前备份，确认保存结果后才覆盖数据。保存失败时优先重试或导出候选；普通延迟编辑在突然断电前仍可能尚未落盘。

本轮没有自动切换日常程序或快捷方式。候选安装验收通过后再切换，保留旧程序与两种备份作为回退依据。
