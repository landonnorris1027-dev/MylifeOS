## 已实现

- 持续显示保存状态；失败时读取已落盘数据、暂停编辑和计时器，保留候选快照用于重试或导出。
- 退出前保存失败时提供返回应用、重试、明确放弃退出；不静默丢弃失败快照。
- 主文件与备份都不可读时阻止普通写入。显式恢复前保存损坏原文件副本，副本保存失败即停止。
- 检查外层存储及内部业务数据，防止合法 JSON 中的非法业务记录覆盖可用备份。
- 主文件及 `.bak` 均先准备完整临时文件再替换，避免更新备份时破坏上一个完整副本。
- schema v5 备份包含业务数据和五组用户设置；预览显示记录数量与过滤数量。旧格式缺少设置时保留当前偏好；拒绝未来格式。
- 导入备份保留自身字段有效、但关联习惯规则已删除或缺失的任务，避免历史记录和专注统计缩水；其他非法任务仍按字段校验过滤。
- Electron 桌面计时器启动失败时不回退到 renderer/browser 计时器；界面显示可重试错误并清除未启动的会话状态。仅无桌面桥接时使用浏览器计时器。
- 导入在候选快照验证后一次性提交，确认落盘后才报告成功。从文件或恢复点还原均先保存当前数据备份，取消或失败即中止。
- 原有 5 个未提交文件中的耐久性修复与强制终止测试保留并整合；不修改日常使用的数据目录。
