# 安卓版验证与验收边界

验收规格见 SPEC.md，架构、签名和复现命令见 IMPLEMENTATION.md。
最终机器验证记录由 `npm run android:verify` 写入 `out/android/verification.json`；完整日志位于 `out/android-verification-run.log`。
记录包含准确的源码提交、工作区状态、源码树摘要、版本、APK 摘要、证书指纹、大小与每项检查。

## 自动验证范围

| 入口 | 验证内容 | 边界 |
|---|---|---|
| android:verify | 共享类型与 Jest、Electron 合约类型、生产构建、Capacitor 同步、原生 JVM 规则、Lint、APK、仪器测试 APK 编译 | 不安装到手机，不代表仪器测试已执行 |
| verify:p0-native | Electron 原生保存/取消/失败对话框及退出重试/丢弃 | 已执行通过，桌面回归范围 |
| android:verify:emulator | 新专用 AVD 上旧包种数据、覆盖升级、迁移断言、8 项原生存储故障测试、启动截图 | 本机 AVD 未完成启动，尚未执行 |

共享测试覆盖写失败和候选重试、快速写入、查询与写入交错、整体导入锁、replace 重试、计时操作确认丢失、启动读取失败、损坏缓存、v4/v6/v7 历史记录与振动兼容、未完成/不可查询会话门禁、文件保存取消与关闭失败、完成持久化后选择休息、关闭面板继续运行。
10 项原生 JVM 规则测试覆盖完成账本去重、延迟截止、提前完成、暂停、旧页面写入保护、休息及历史孤立记录与无效输入。
8 项原生存储仪器测试、旧包种数据、新版升级验证和包名检查均有源码；必须在隔离设备执行后才能验收。
