# 安卓 0.1.4 实施规格

依据用户确认的计划执行，基线为主线 e135105；安卓原生工程来自 170e8bf。
个人离线 APK，优先可靠性与日常效率；专注结束立即保存，再选择休息。

## P0-A
- 共享主线 React 业务；Electron、Android、浏览器由平台适配层选择。
- 应用私有 AtomicFile JSON，串行写入，独立上一份有效快照；原生会话与业务同一快照。
- 保存中、已保存、失败、恢复；失败冻结编辑，保留候选，可重试、导出。
- 首次读取迁移 Preferences、WebView、脏标记及未完成会话，保留原来源。
- 导入、恢复、跨日改期整体提交；覆盖前成功保存恢复点，最多七个。
- 保留孤立历史完成任务与分钟。默认 v7 含振动，支持 v1–v6；显式 v6 兼容导出不含振动。

## P0-B
- 任务、分钟、稳定会话 ID 完成标记同一事务；前台、原生广播、重启补记最多一次。
- 开始、暂停、继续、停止等候持久化；查询失败不能当作没有会话。
- 提醒去重、通知及渠道与精确闹钟状态入口；无权限提示可能延迟，返回应用重核。
- 未结束会话阻止导入恢复；关闭计时面板继续运行；完成记录后选择休息。

## P1
- 手机待办/时间轴切换、固定新增、当前时段、触屏操作与至少 48dp 主要目标。
- 搜索、临时任务跨日改期、十秒撤销、工作日/自选星期沿用主线。
- 分开习惯与设置；安全区域、系统返回、键盘与弹窗适配。

## P2 与验收
- 独立 android:verify：共享测试、类型、原生单元、Lint、APK、仪器测试编译。
- 固定个人证书，与旧 APK 指纹核对；release 关闭调试；产物记录源码、版本、证书、SHA256、验证边界。
- 故障：快速写入/写失败/中途进程结束/主文件损坏；整体导入失败旧数据完整；取消保存不覆盖；历史数与分钟不减少。
- 专注：前台、锁屏、关闭页面、进程回收、重启去重，原截止时间计算。
- 兼容：旧数据、v4/v6、桌面 0.1.3 v6 往返、同证书安装升级。
- UI：360–430dp、键盘、系统返回全流程。设备：Android 7/13/16 与目标手机。
- 设备与安装实测必须单独记录；没有设备时不能把静态检查/编译声称为送达或升级通过。
