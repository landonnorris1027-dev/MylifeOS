# 画像页图表与周复盘改进

## 批准范围与视觉规则

2026-10-09，用户批准“按照你的适配建议更改，一定要保证风格统一”。对应建议：白底蓝色总览、计划与实际对比柱、正负偏差图、紧凑周复盘及移动窗口适配。实施于 `codex/windows-ui-motion`，固定基线 `ebf10ef80ab42b34d7622fdb265f01a71a39e527`。此次为 Windows 画像页改进，未合并主分支或安装发布。

沿用规划页白色画布、Google 蓝 `#0b57d0`、系统字体、Lucide 图标、24px 面板圆角与胶囊按钮。计划对比与偏差图使用深浅蓝，完成任务环形图使用优先级语义色，辅助文字至少13px；优先级仍保留红、黄、绿、紫的语义色。复用已有 `SegmentedControl`，未添加图表依赖。

- [Tremor Support overview](https://overview.tremor.so/support)：白底信息层级与总览密度。
- [shadcn 分组柱图](https://ui.shadcn.com/view/new-york-v4/chart-bar-multiple)：同刻度计划／实际对比。
- [shadcn 正负柱图](https://ui.shadcn.com/view/new-york-v4/chart-bar-negative)：偏差方向的呈现。

## 行为与口径

- 三项全历史指标保留；周目标仅计实际计时，始终采用参考日期所在的本地周一至周日，近七天筛选不改变周目标口径。
- 七天计划与实际使用共同的零起点比例。零值不补高度；历史估算在明细中单独显示，不混入实际或偏差。
- 可通过点击、悬停或键盘聚焦读取任一日数值；原每日表格保留于“查看每日明细”。
- 偏差为实际减计划，正负方向清楚，历史估算不参与计算。时间展示仍为整分钟，未修改存储的秒精度。
- 目标投入区域按用户确认替换为每日／每周完成任务环形图：按已完成任务的实际专注时长分配 P1红、P2黄、P3绿、临时任务紫的颜色占比。
- 周复盘保留全部任务、笔记、复盘与关联会话，每页25项。切换日期／时段重置页码，刷新时缩短列表仍夹紧页码。状态与会话类型显示中英文。
- 同一任务ID在不同日期的会话按ID及任务日期共同匹配，避免复盘详情混入另一日的会话。独立会话仍计入汇总并显示说明。
- 年度热力图保留原蓝色阈值与数据来源，放大桌面网格；窄窗口内部横向滚动，图例保持可见。Android适配器及其历史统计口径保持原逻辑。
- IPC、持久化、备份schema与计时业务接口均未改动；图表互动仅修改页面临时状态。

## 每日／每周环形分布补充（2026-10-09）

用户明确选择“按已完成任务的实际专注时长”。每日使用复盘参考日期，每周固定使用该日期所属的本地周一至周日，与“近七天”分析筛选独立。桌面两卡并排、窄窗口上下排列，借用用户图3的细环与左侧百分比图例；白底、圆角和系统字体继续沿用画像页。

- 分母为范围内目前状态是completed的任务所关联的measured会话实际专注秒数之和；每类用其实际时长除以该总时长。先按原始秒数计算占比，再以分钟展示时长，不按任务数量或计划时长加权。
- 同一完成任务此前主动停止的实际专注也计入其投入。未完成／撤销完成／已删除任务、估算、仅有旧任务历史时长及找不到原任务的独立会话不进入该环形图；原全历史计时指标仍保留这些记录的原统计规则。
- 日期归属使用原任务日期及ID匹配，跨午夜不拆分。习惯采用会话记录的优先级，缺失时回退到任务优先级；已有及新增临时任务均归紫色。
- 零数据为灰色空环、各类0.0%；单一类别为整环。正值不足一分钟显示“<1分钟”，不会显示秒或将非零投入误写为0分钟。中心显示该日／周的完成任务实际总分钟数。
- SVG提供完整分类、百分比、分钟与日期的可访问名称。仅增加展示层汇总，未改公开接口、存储或计时流程。
- 类型及18项相关测试通过，覆盖完成状态筛选、实际时长加权、估算排除、日／周归属、旧临时任务、历史习惯优先级、空环及单类不足一分钟。
- 中英文检查390、768、1280、1440、1920px宽度；桌面200%对应有效布局宽度640／720／960px，未发现溢出和图例／环重叠。日期切换更新日环与周环，“近七天”切换不改变周环。局部调整由主Agent实际看图自检，未新增独立视觉评审或动效。
- 新证据位于 `profile-distribution/`；全部使用隔离虚构数据。GitHub Windows candidate验证以此次提交的对应Actions run为准。


## 分段粗环样式补充（2026-10-10）

根据用户提供的 Arc 截图，将日／周分布改为粗环、圆角分段和白色间隙。中央以大数字呈现实际总分钟数，下方按「分类色点／时长／百分比」对齐；保留纯白底、现有圆角与字体、P1红／P2黄／P3绿／临时紫。桌面两卡并排，窄窗口上下排列；其他画像内容与已完成任务实际专注时长的汇总口径保持原逻辑。

- 使用填充 SVG 圆环扇区，仅对扇区四角做小圆角，避免粗描边圆头扩张小占比；白色间隙留在各类原有角度范围内。极小扇区减少间隙与圆角，单类100%为无断缝整环；零值仍为灰色空环。
- 图例从圆环侧面移到下方，时长与百分比各占独立对齐列，圆点对应色段。保留日期、统计口径、全部分类与可访问摘要，未删业务文案；中心增加「实际专注」说明。
- 类型检查与18项相关行为测试通过。独立浏览器检查中英文390／768／1280／1440／1920px及桌面200%有效宽度，日期、周范围和空状态通过，无横向溢出、图例重叠或控制台错误。
- 另用浏览器SVG实际路径验证0.01%、0.1%、3%、50%、95%、99.99%、100%七种占比：有效闭合路径、中心留白、扇区保持在圆环内、非满环起始分隔可见。采样允许0.1 SVG单位的浏览器曲线近似误差；此容差不会改变源路径或统计占比。
- 本轮为局部组件精修，由主Agent查看桌面、手机与200%实际截图自检，未新增独立评审或动效。截图使用固定2026-10-09日期的隔离虚构数据；日常数据未改动。
- 证据：`profile-distribution/segmented-desktop.png`、`segmented-mobile.png`、`segmented-zoom-en.png`与`segmented-browser-checks.json`；之前的细环截图保留作对比。远端验证以此次提交的Windows candidate Actions运行结果为准。
